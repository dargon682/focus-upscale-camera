# 子计划 05：扩展包系统 + Beta 计划（`0.8.50(N)` 版本号）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. `- [ ]` 跟踪。

**Goal:** 引入"扩展包"（数据资产包：语言包 / 进阶滤镜参数 / 主题包），版本号运行时显示为 `0.8.50(N)`（括号为已启用扩展数）；设置页新增 Beta 计划（声明书，用户同意后自动下载并启用扩展）。

**Architecture:** 扩展包即数据式资产，定义见子计划03 `DataPlugin`。新增 `ExtensionManager` 维护"已启用扩展"清单与计数；`About`/设置页用 `BuildConfig.VERSION_NAME + "(" + extCount + ")"` 展示。Beta 计划复用下载通道（增强后的 `DownloadService`）拉取扩展清单并自动启用。

```java
public final class AppVersion {
    private AppVersion() { }
    public static String display(Context c) {
        int n = extCount(c);
        return BuildConfig.VERSION_NAME + "(" + n + ")";
    }
    public static int extCount(Context c) { return Prefs.extCount(c); }
}
```

- [ ] **Step 2: `Prefs.extCount`**

```java
public static int extCount(Context c) { return sp(c).getInt("ext_count", 0); }
public static void putExtCount(Context c, int n) { sp(c).edit().putInt("ext_count", Math.max(0, n)).apply(); }
```

- [ ] **Step 1: Beta 声明书（strings.xml）**

说明：Beta 计划会提前下载并启用扩展数据包，功能可能伴随不稳定；同意后自动更新；可随时退出（退出即停止扩展自动更新，已装扩展进入待卸载确认）；数据写入需遵循隐私政策。

- [ ] **Step 2: `Prefs`**

```java
public static boolean betaPlan(Context c) { return sp(c).getBoolean("beta_plan", false); }
public static void putBetaPlan(Context c, boolean v) { sp(c).edit().putBoolean("beta_plan", v).apply(); }
```

- [ ] **Step 3: 设置页新增 Beta 计划行**：首开弹声明书；同意后 `putBetaPlan(true)` 并触发 `syncBetaExtensions()`（拉取 `version.json` 的 `extensions` 列表 → 走 `DownloadService` 逐个下载数据资产 → `ExtensionManager.enable` → `putExtCount` 更新 → 提示"扩展已安装，版本 X(N)"）。
