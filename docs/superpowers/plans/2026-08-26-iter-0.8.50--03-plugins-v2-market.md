# 子计划 03：插件系统 v2 —— 新增语言包类型、数据式插件解释器与插件市场

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. `- [ ]` 跟踪。

**Goal:** 在现有 `Plugin`/`PluginRegistry` 基础上新增 `LANGUAGE` 插件类型与内置英文语言包；实现数据式插件（语言包/滤镜参数/主题配色）的下载、解释与应用；实现插件市场浏览/下载，并按账号等级控制可用范围。

- [ ] **Step 1: `LanguageManager`**

```java
public final class LanguageManager {
    private static LanguagePackPlugin active;
    public static void setActive(LanguagePackPlugin p) { active = p; }
    public static String t(Context c, int resId, String enDefault) {
        if (active != null) { String s = active.tr(c.getString(resId), enDefault); return s; }
        return c.getString(resId); // 默认中文
    }
}
```

- [ ] **Step 2: 注册内置英文包（`PluginRegistry.languages()`）**
