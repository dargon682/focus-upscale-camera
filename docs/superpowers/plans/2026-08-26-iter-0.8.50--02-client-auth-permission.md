- [ ] **Step 1: `ApiClient`（GET/POST + JSON，超时 10s）**

```java
public final class ApiClient {
    public static JSONObject call(String path, String token, JSONObject body) {
        HttpURLConnection c = (HttpURLConnection) new URL(ApiConfig.BASE + path).openConnection();
        c.setConnectTimeout(10000); c.setReadTimeout(15000);
        c.setRequestProperty("Content-Type", "application/json");
        if (token != null) c.setRequestProperty("Authorization", "Bearer " + token);
        if (body != null) { c.setRequestMethod("POST"); c.setDoOutput(true);
            c.getOutputStream().write(body.toString().getBytes(StandardCharsets.UTF_8)); }
        int code = c.getResponseCode();
        InputStream in = code >= 400 ? c.getErrorStream() : c.getInputStream();
        String s = new String(readAll(in), StandardCharsets.UTF_8);
        JSONObject o = new JSONObject();
        o.put("code", code); o.put("body", s.length() > 0 ? new JSONObject(s) : null);
        return o;
    }
}
```
