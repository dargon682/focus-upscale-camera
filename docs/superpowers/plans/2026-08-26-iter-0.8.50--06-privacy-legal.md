**Goal:** 在设置页"关于"内新增可查看的**隐私声明**与**法律声明**（纯文本页/对话框），并与 Beta 计划、体验增强计划声明书保持一致引用。

**Files:**
- Modify: `/workspace/photo-tool/app/src/main/res/values/strings.xml`
- Modify: `/workspace/photo-tool/app/src/main/java/com/photo/tool/SettingsActivity.java`

- [ ] **Step 1: 隐私声明文案（strings.xml `string/privacy_statement`）**

覆盖：① 相机照片默认本地保存、不上传服务器；② 仅当开启"用户体验增强计划"才采集技术类行为数据（不含照片像素、通讯录），gzip 压缩分批、后端 D1 存储并按 admin 导出；③ 账号数据（用户名/邮箱/哈希密码/等级/授权期）存于开发者 GitHub 仓库 `server-data/` 目录以支撑登录与权限；④ 网络请求仅访问后端 API 与更新/插件下载源；⑤ 用户可随时关闭采集并请求删除账号数据（联系 admin）；⑥ 联系方式占位。

- [ ] **Step 2: 法律声明文案（strings.xml `string/legal_statement`）**

覆盖：① 软件许可（个人学习/非商业用途，禁止篡改、逆向、商用分发重打包）；② 免责声明（相机成像质量与超分结果不作专业摄影保证）；③ 知识产权（品牌、图标、文档版权归本项目所有）；④ 账号与数据责任（用户对账号使用与上传内容负责，开发者对第三方数据式插件不含恶意代码的审查尽力而为但不对第三方行为担责）；⑤ 保留随时修改条款并更新的权利，重要变更于版本更新日志公告。

- [ ] **Step 3: 关于区新增两个入口**：`AlertDialog`（滚动 TextView + 关闭）展示上述两类文本；在关于页版本区域下方列出"隐私声明""法律声明"两行。

- [ ] **Step 4: 与声明书一致性**：Beta 计划声明书、体验增强计划声明书在正文末尾引用"详见关于→隐私声明/法律声明"。
