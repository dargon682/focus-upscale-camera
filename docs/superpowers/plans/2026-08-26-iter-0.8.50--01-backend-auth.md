# 子计划 01：后端账号与权限系统（Cloudflare Workers + GitHub 存储）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. `- [ ]` 跟踪。

**Goal:** 交付可部署到 Cloudflare Workers 的后端，实现注册(邮箱验证)/登录/登出、权限校对（含封禁与授权期）、管理员面板 API、批量分发、插件市场上架审批、行为数据接收，账号等结构化数据写入本仓库 `server-data/`。

**Architecture:** 无服务器 Worker + KV(会话/邮箱验证码) + D1(行为数据)。账号/市场主数据经 GitHub Contents API 写入仓库 `server-data/`。管理员与 seed 账号 `admin` 首次初始化写入。

**Tech Stack:** TypeScript（Worker）、Hono（可选路由，或用原生 `fetch` 事件）、Cloudflare KV/D1、GitHub REST API、bcryptjs、jsonwebtoken。

**运行方式（本地）:** `wrangler dev`（绑定 KV/D1 由 `wrangler.toml` 指定）；线上部署见末尾。

- [ ] **Step 4: 首轮实现 `src/github/Storage.ts`*（GitHub Contents API 封装，账号主数据读写）**

```ts
export interface GhFile { content: string; sha: string; }
export class GitHubStorage {
  private base = "https://api.github.com";
  constructor(
    private token: string,
    private owner: string,
    private repo: string,
    private root: string, // server-data
    private kv: KVNamespace, // 锁与缓存
  ) {}
  private url(p: string) { return `${this.base}/repos/${this.owner}/${this.repo}/contents/${this.root}/${p}`; }
  private async req(method: string, p: string, body?: unknown, sha?: string) {
    const r = await fetch(this.url(p), {
      method,
      headers: { Authorization: `Bearer ${this.token}`, Accept: "application/vnd.github+json", "X-GitHub-Api-Version": "2022-11-28", "Content-Type": "application/json" },
      body: body ? JSON.stringify({ message: `[server-data] ${method} ${p}`, content: btoa(JSON.stringify(body)), sha, branch: "main" }) : undefined,
    });
    return r;
  }
  async read(p: string): Promise<GhFile | null> {
    const r = await fetch(this.url(p), { headers: { Authorization: `Bearer ${this.token}`, "User-Agent": "photo-tool" } });
    if (r.status === 404) return null;
    const j: any = await r.json();
    return { content: JSON.parse(atob(j.content)), sha: j.sha };
  }
  /** 乐观写入：先读现状，若 sha 变则重试 3 次（指数退避）。 */
  async write(p: string, data: unknown): Promise<void> {
    let attempt = 0;
    while (attempt < 3) {
      const cur = await this.read(p);
      const r = await this.req("PUT", p, data, cur?.sha);
      if (r.ok) return;
      attempt++; await new Promise(res => setTimeout(res, 300 * 2 ** attempt + Math.random() * 400));
    }
    throw new Error("GITHUB_WRITE_FAILED");
  }
}
```

`src/github/User.ts`：
```ts
export type Level = "none" | "user" | "user_pro" | "developer" | "admin";
export const LEVEL_RANK: Record<Level, number> = { none: 0, user: 1, user_pro: 2, developer: 3, admin: 4 };
export interface User {
  id: string; username: string; email: string;
  passwordHash: string; level: Level; authExpireAt: number; // -1=永久
  status: "active" | "banned"; createdAt: number; lastLoginAt: number;
  emailVerified: boolean; pendingRegistration: boolean;
}
export function genId(): string {
  const c = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
  return Array.from({ length: 15 }, () => c[Math.floor(Math.random() * c.length)]).join("");
}
export function expired(u: User, now: number): boolean {
  return u.authExpireAt !== -1 && now > u.authExpireAt;
}
export function usable(u: User, now: number): boolean {
  return u.status !== "banned" && !u.pendingRegistration && !expired(u, now);
}
```

import jwt from "jsonwebtoken";
export function sign(userId: string, secret: string): string {
  return jwt.sign({ sub: userId }, secret, { expiresIn: "30d" });
}
export function verify(token: string, secret: string): string | null {
  try { const p: any = jwt.verify(token, secret); return p.sub; } catch { return null; }
}
